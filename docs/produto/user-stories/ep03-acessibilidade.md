# Histórias de Usuário - Épico 03 (Acessibilidade Universal & Interação por Voz)

## US09: Modo de alto contraste e tipografia ampliada
* **Declaração:** Como Fátima, quero ativar o modo de alto contraste e tipografia ampliada, para que eu consiga ler as informações na tela sem forçar a visão.
* **Contexto de uso:** A passageira tem dificuldade de visão e interage com o totem público sob diferentes condições de iluminação, precisando de uma interface mais legível.
* **Critérios de Aceitação:**
  * Dado que o totem está exibindo a interface padrão.
  * Quando a passageira seleciona a opção de acessibilidade visual.
  * Então o sistema deve alterar para um tema de alto contraste, além de aumentar o tamanho da fonte para todo texto.
* **Prioridade:** Should Have.

## US10: Navegação não dependente de cores
* **Declaração:** Como Fátima ou um usuário daltônico, quero navegar pelo sistema sem depender exclusivamente de cores para identificar informações e botões, para que eu possa usar o totem sem me confundir.
* **Contexto de uso:** O usuário com visão debilitada ou daltonismo precisa interpretar ações, rotas e alertas na tela do totem físico.
* **Critérios de Aceitação:**
  * Dado que o sistema exibe informações de rotas, alertas ou botões de ação.
  * Quando o usuário visualiza a interface.
  * Então o sistema deve utilizar ícones, padrões gráficos e textos descritivos complementares, não dependendo apenas da cor para transmitir a mensagem.
* **Prioridade:** Should Have.

## US11: Leitura sintetizada em áudio das informações
* **Declaração:** Como Kleber, quero ouvir a leitura sintetizada em áudio das informações da tela, para que eu saiba quais os ônibus, horários e rotas estão disponíveis mesmo com minha deficiência visual.
* **Contexto de uso:** O passageiro com deficiência visual encontra-se no ponto de ônibus e precisa de feedback auditivo do totem para acessar as informações de forma autônoma.
* **Critérios de Aceitação:**
  * Dado que o totem está na tela inicial ou de detalhes de uma linha.
  * Quando o usuário ativa a função de acessibilidade de áudio.
  * Então o sistema deve realizar a leitura clara e sintetizada em áudio dos textos e opções selecionadas na tela.
* **Prioridade:** Should Have.

## US12: Interação por comandos de voz
* **Declaração:** Como Kleber, quero interagir com o totem através de comandos de voz, para que eu possa pesquisar linhas e itinerários sem precisar encontrar ou tocar na tela.
* **Contexto de uso:** O usuário possui severa limitação visual ou motora e precisa buscar informações de transporte falando diretamente com o equipamento.
* **Critérios de Aceitação:**
  * Dado que o totem possui o sistema de captação de áudio ativo.
  * Quando o usuário fala um comando válido (ex: "Buscar linha para o centro").
  * Então o sistema deve processar o comando de voz, realizar a busca e fornecer a resposta em áudio e na tela.
* **Prioridade:** Could Have.
