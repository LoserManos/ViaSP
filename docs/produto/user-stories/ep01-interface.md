# Histórias de Usuário - Épico 01 (Interface & Experiência do Totem)

## US01: Visualização das linhas disponíveis no ponto e seus sentidos
* **Declaração:** Como Fátima, quero visualizar as linhas disponíveis no ponto e seus sentidos, para que eu saiba rapidamente quais ônibus passam ali através de uma interface clara.
* **Contexto de uso:** O sistema opera em um totem público físico, e a passageira idosa precisa de navegação intuitiva ao chegar ao local.
* **Critérios de Aceitação:** 
  * Dado que o totem está aguardando na tela inicial.
  * Quando a passageira visualiza a interface.
  * Então o sistema deve exibir a lista das linhas disponíveis no ponto e seus respectivos sentidos.
* **Prioridade:** Must Have.

## US02: Busca rápida e seleção de linha por toque/teclado virtual
* **Declaração:** Como Arthur, quero buscar e selecionar uma linha através de toque ou teclado virtual, para que eu consiga realizar a consulta com agilidade e objetividade.
* **Contexto de uso:** O passageiro habitual precisa de agilidade na consulta diretamente no totem físico.
* **Critérios de Aceitação:**
  * Dado que o passageiro visualiza a tela inicial do totem.
  * Quando ele utiliza o toque ou o teclado virtual para pesquisar uma linha.
  * Então o sistema deve realizar a busca rápida e permitir a seleção da linha desejada.
* **Prioridade:** Must Have.

## US03: Exibição do itinerário simplificado, destino e paradas principais
* **Declaração:** Como Fátima, quero visualizar o itinerário simplificado, o destino e as paradas principais, para que eu possa confirmar a rota através de uma interface clara.
* **Contexto de uso:** O usuário interage com a tela do totem público para confirmar os detalhes do trajeto de um ônibus específico.
* **Critérios de Aceitação:**
  * Dado que o passageiro selecionou uma linha no totem.
  * Quando a tela de detalhes for carregada.
  * Então o sistema deve exibir o itinerário simplificado contendo o destino final e as paradas principais da rota.
* **Prioridade:** Must Have.

## US04: Retorno automático à tela inicial após período de inatividade
* **Declaração:** Como Arthur, quero que o sistema retorne automaticamente à tela inicial após um período de inatividade, para que o totem esteja pronto para a minha consulta com agilidade quando eu chegar.
* **Contexto de uso:** Totens físicos compartilhados por múltiplos passageiros no ambiente público, garantindo a privacidade e o fluxo de uso da interface.
* **Critérios de Aceitação:**
  * Dado que o totem está exibindo detalhes de uma busca anterior.
  * Quando houver um período de inatividade na interação com a interface.
  * Então o sistema deve efetuar o retorno automático à tela inicial.
* **Prioridade:** Should Have.
